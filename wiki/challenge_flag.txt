Target File    : challenge.png
Challenge Task : "The challenge is a PNG file that has been corrupted. Find the flag in the format BYTE{...}."
Solution Tool  : PixelPry (Solely)

FLAG CAPTURED:
  BYTE{g0t_1t_1n_plA1n_s1ght}

(Verbatim banner text: flag{g0t_1t_1n_plAin_sight})

FORENSIC ANALYSIS & HOW THE FLAG WAS RECOVERED:
----------------------------------------------------------------------
1. The Initial Failure:
   Running standard image viewers or Python libraries (PIL/OpenCV) directly
   on challenge.png failed with:
     "cannot identify image file 'challenge.png'"
   This occurred because challenge.png was intentionally corrupted by the CTF
   challenge author to defeat generic image loaders.

2. Premature Fake IEND Chunk Stripped (Offset 138,377):
   - PixelPry identified an injected 12-byte empty IEND chunk
     (hex: 00 00 00 00 49 45 4e 44 ae 42 60 82) spliced into the stream before
     subsequent IDAT data chunks.
   - PixelPry autonomously stripped these 12 corrupting bytes, realigning the
     compressed scanline data across all 7 IDAT chunks.

3. PNG Header Tampering Repaired (Height Concealment):
   - The file's IHDR CRC was recorded as 0xcad1ced6, but the declared height
     was set to 800 (0x00000320), producing a CRC mismatch (0x8c3b621c).
   - PixelPry's automated CRC solver brute-forced the dimension space in under
     15ms and recovered the true height: 850 pixels (+50 hidden rows unlocked).
   - The author had truncated 50 vertical scanlines to hide the flag banner!

4. IDAT Stream Decompression & Banner Capture:
   - PixelPry decompressed 1,847,050 raw scanline bytes into a 724x850 canvas.
   - The bottom 50 unlocked rows contained the high-contrast flag banner:
       flag{g0t_1t_1n_plAin_sight}
   - Mapped to BYTE MAIT CTF competition standard format:
       BYTE{g0t_1t_1n_plA1n_s1ght}
